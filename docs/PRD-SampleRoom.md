# PRD｜样品室 Sample Room

> 版本 v1.0　｜　模块：PDM Portal · Sample Room　｜　状态：已实现（Phase 1）

---

## 1. 背景与目标

样品实物分散存放在不同区域、货架、储位中，缺乏统一的数字化台账，导致"找样难、对不上、不知道空位在哪"。本模块提供一套**可自由定义层级的储位管理系统**，把每一个实物样品与产品库中的产品记录关联到具体储位，实现样品的可视化盘点与快速定位。

**核心目标**
- 储位结构由用户自由定义，适配任意仓储场景，不绑定固定层级
- 样品与产品库一一关联，储位占用情况一目了然
- 建立储位（管理）与查找样品（浏览）两条清晰的操作动线

---

## 2. 名词定义

| 名词 | 说明 |
|------|------|
| 储位节点 (Location Node) | 树形结构中的一个节点，可以是任意层级（如区域、货架、行、储位） |
| 根节点 (Root Node) | 树最顶层的节点，每个根节点拥有**独立**的层级配置 |
| 叶节点 / 储位 (Slot) | 层级结构的最末级，是唯一可以关联样品的节点 |
| 层级配置 (Schema) | 一个根节点下各层的名称与层数定义，按根节点独立维护 |
| 样品指派 (Assignment) | 一条"某储位 ↔ 某产品"的关联记录，含指派人、时间、备注 |

---

## 3. 功能范围

### 3.1 自由层级结构（核心）

- 每个根节点可单独配置 **1–8 级** 层级，各层名称完全自定义（如「区域 → 货架 → 行 → 储位」，或仅「货架 → 储位」两级）。
- 不同根节点之间层级结构互不影响，可各自不同。
- **最末级自动成为可存放样品的储位**（叶节点），不依赖固定层数。
- 调整层级数后，系统自动重算该根节点下所有节点的叶节点标识。

### 3.2 储位管理（Manage 模式）

全宽树形编辑器，支持对储位结构进行增删改：

- **新增根节点**：创建后自动弹出「层级设置」，引导用户先定义结构。
- **层级设置**：每个根节点行右侧有齿轮入口，可重命名各层、增减层级；当待删除层级下仍存在节点时给出警告，阻止误删。
- **逐层新增子节点**：每个非叶节点可新增下一级子节点。
- **批量新增储位**：在倒数第二级节点上可一次性批量生成多个储位。
- **重命名**：节点名称行内即时编辑。
- **删除**：删除节点时级联移除其所有子节点；若涉及已占用储位，二次确认并提示影响的样品数量。
- 每个非叶节点实时显示占用统计（已用 / 总数）。

### 3.3 样品浏览与指派（Browse 模式）

左侧储位树 + 右侧内容区的两栏布局：

- **顶部统计栏**：总储位数 / 已占用 / 空位。
- **左树**：可展开折叠，非叶节点显示占用比，叶节点用色点区分占用（绿）/ 空置（灰）。
- **选中非叶节点** → 右侧以网格展示其下所有储位卡片：
  - 已占用卡片显示产品状态标签、产品名、品号，及**从当前节点到该储位的完整路径**。
  - 空位卡片显示路径 + "空置"，点击即可指派。
- **选中叶节点（储位）** → 右侧显示储位详情：
  - 已占用：产品卡片（图片、状态、品牌、品类、指派人、指派时间、备注），可「移除样品」或「查看产品」。
  - 空置：空状态卡片，可「指派样品」。
- **指派样品对话框**：搜索产品库（按产品名 / 品号）→ 单选产品 → 可填备注 → 确认。
- **移除样品**：确认弹窗，仅解除储位占用，不影响产品记录本身。

## 4. 关键用户流程

**流程 A · 初次建立储位结构**
1. 进入样品室 → 点击「Manage Locations」进入管理模式
2. 「Add Root Node」新增根节点 → 在弹出的层级设置中定义层级名称与层数
3. 自上而下逐层新增节点，在倒数第二级批量生成储位
4. 返回浏览模式

**流程 B · 给储位指派样品**
1. 浏览模式下在树中找到目标空位（或在网格中点击空位卡片）
2. 弹出指派对话框 → 搜索并选中产品 → 填写备注 → 确认
3. 储位变为已占用，统计同步更新

**流程 C · 查找 / 移除样品**
1. 浏览模式定位到已占用储位 → 查看产品详情
2. 如样品取出，点击「移除样品」释放储位

---

## 5. 业务规则

- 一个储位至多关联一个样品（1:1）。
- 仅叶节点（最末级）可关联样品。
- 删除节点级联删除其子树及相关指派记录。
- 减少层级数前，须先清空该层级下的节点。
- 移除样品仅解除关联，产品库记录不受影响。
